# SkyShift

**Zoom through time in NASA SPHEREx sky images.** Watch asteroids crawl over hours, distant
worlds drift over days, and compare whole survey passes months apart. The "Hunt Planet X" game
trains you on planted fake movers, then lets you flag real ones on a shared candidate board.

This Space runs the code from **https://github.com/Mahadi5577/skyshift**, where you will find the
documentation, the experiments behind the design and how to cite it
([DOI 10.5281/zenodo.23181747](https://doi.org/10.5281/zenodo.23181747)). It is deployed from
GitHub; please send issues and changes there.

SkyShift is an independent project, not affiliated with or endorsed by NASA. SPHEREx data come
from the NASA/IPAC Infrared Science Archive (IRSA).
